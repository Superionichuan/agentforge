# AgentForge website

Static site for AgentForge, an open, co-created community of scientists who build AI agents for research.
It grew from AgentForge 2026, a hands-on workshop at Nanyang Technological University, Singapore (15–19 November 2026), supported by Schmidt Sciences.

- `index.html`: home page
- `showcase.html`: open materials and hackathon projects
- `assets/`: styles, logos and images

The programme and venue of the 2026 workshop stay on the original site: https://agentforgeworkshop.github.io/workshop-site/

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
