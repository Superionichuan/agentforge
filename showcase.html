Open Materials

Five tutorials

Slides for all five tutorials, and hands-on notebooks for four of them, several of which run in Colab with no local installation. Tutorial 4 runs a self-hosted agent in Docker.

  1. From chatbot to agent: an agent loop in plain sight with mini_agent, and the same agent in LangChain, Pydantic AI and DeepAgents
  2. Agentic memory
  3. A research MCP server and Agent Skills, with tests and continuous integration
  4. Multi-agent systems, with a self-hosted agent in Docker
  5. Evaluating a paper-triage agent: code and LLM-judge graders, pass@k
github.com/AgentForgeWorkshop/Tutorials

Hackathon Showcase

Teams built research agents during the workshop and evaluated them before presenting. Their code is public.

Sanity

A multi-agent checker that finds mathematical errors in papers. The language model proposes; a computer algebra system and Lean decide.
