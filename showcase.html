What the workshop left behind

Open tutorials, an open-source teaching agent, and the research agents that teams built during the hackathon. All of it is public.

Open materials

Five tutorials

Each tutorial comes with slides and a Colab notebook that runs without any local installation.

  1. From chatbot to agent: an agent loop in plain sight with mini_agent, and the same agent in LangChain, Pydantic AI and DeepAgents
  2. Agentic memory
  3. A research MCP server and Agent Skills, with tests and continuous integration
  4. Multi-agent systems, with a self-hosted agent in Docker
  5. Evaluating a paper-triage agent: code and LLM-judge graders, pass@k
github.com/AgentForgeWorkshop/Tutorials

mini_agent 2.0.0open source

The teaching agent from Tutorial 1, released on 23 November 2026 as an open-source package under the MIT licence. It installs with one command on macOS, Linux and Windows.
